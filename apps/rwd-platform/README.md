# ESGGO 全能力 RWD 平台

整合本機與遠端倉庫（Omniesggo + OmniNote）全部能力的響應式平台，採 Mobile-First 與最佳實踐 UI/UX。

## 啟動

```powershell
cd apps/rwd-platform
pnpm dev   # http://localhost:52800
```

## 能力

- A01~A08 核心治理設施矩陣
- OmniNote 萬能筆記（速記、雙鏈圖譜、證據鏈、搜尋、標籤、草稿、匯入匯出）
- 5T 終始矩陣協議

## RWD 斷點

360 / 768 / 1024 / 1280 / 1440px，支援深淺主題切換、鍵盤導覽、skip link。
