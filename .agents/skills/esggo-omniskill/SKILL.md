# ESG GO Omniskill

This skill package enforces the Global Healing standards across all ESG GO project implementations.

## Core Principles
- English Standard (Traditional Chinese Broad): All documentation/code in English with traditional Chinese localization
- End-to-End Matrix: Data flow from source to frontend
- Bidirectional TypeScript: Full stack type safety
- Next.js: App Router with Server Components
- Google Stitch: UIUX design via StitchMCP

## Implementation Guidelines
1. [Type Safety](#type-safety)
2. [Naming Conventions](#naming-conventions)
3. [Component Structure](#component-structure)

### 1. Type Safety
- Never use `any` type
- Define interfaces for all data models
- Use строгие типы (strictType) for API responses

### 2. Naming Conventions
- PascalCase for classes/components
- camelCase for props/variables
- Consistent English names with traditional Chinese counterparts

### 3. Component Structure
- Follow Next.js `app/` directory structure
- Use Google Stitch for UI generation
- Archive design systems as reusable .pen files
