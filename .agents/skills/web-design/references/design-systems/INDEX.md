# Design Systems Index

58 個真實網站的設計系統預設，來源於 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)（MIT License）。

## 使用方式

**按需讀取，不要全量載入。** 當使用者提到"做一個類似 XXX 的頁面"時，讀取對應檔案獲取完整設計規範。

每個檔案包含 9 個標準化章節：
1. Visual Theme & Atmosphere — 設計哲學和氛圍
2. Color Palette & Roles — 完整色彩系統
3. Typography Rules — 字型層級表
4. Component Stylings — 按鈕/卡片/輸入框/導航樣式
5. Layout Principles — 間距/網格/容器規範
6. Depth & Elevation — 陰影體系
7. Do's and Don'ts — 設計護欄
8. Responsive Behavior — 響應式斷點
9. Agent Prompt Guide — 快速參考和元件示例
