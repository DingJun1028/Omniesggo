## 🏷️ 第三奧義：OmniTag 萬能標籤系統

### 3.1 六大維度（MECE）

| 維度 | 範例 | 說明 |
|------|------|------|
| **安全分級** | `public` / `internal` / `confidential` / `restricted` | 資料機密等級 |
| **代理歸屬** | `agent:01` ~ `agent:30`、`squad:智庫聖所` | 責任歸屬 |
| **生命週期** | `lifecycle:draft` / `active` / `frozen` / `archived` | 狀態追蹤 |
| **品質/熵減** | `p0` / `p1` / `p2` / `p3` | P0=阻斷項、P3=噪音 |
| **平台/環境** | `platform:esggo` / `platform:vps` / `platform:firebase` | 部署環境 |
| **結界/繼承** | `best-practice:awakened` / `best-practice:結界` | 最佳實踐覺狀態 |

### 3.2 自動化路由規則

| Tag 組合 | 路由目標 |
|----------|---------|
| `agent:01-06` + `squad:智庫聖所` | Hindsight / 記憶召回 |
| `agent:07-12` + `squad:符文契約` | API / TypeScript / ZKP 修復 |
| `agent:13-18` + `squad:光之羽翼` | 部署 / cron / 自動化 |
| `agent:19-24` + `squad:煉金熵減` | 重構 / lint / test / entropy |
| `agent:25-30` + `squad:5T驗算` | ISO / Hash Lock / 稽核 |
| `best-practice:結界` | 全部自動 inheriting |

### 3.3 驗證規則

1. **必備 Tag**：每個 artifact 至少要有 `agent:*` + `lifecycle:*` + `p*`
2. **結界自動繼承**：一旦標記 `best-practice:結界`，全部子代理自動 inheriting
3. **凍結不可改**：`lifecycle:frozen` + `restricted` 禁止修改
4. **熵減追蹤**：`p0` 任務完成後 entropy 必須下降 `< 0.1`

## 🔒 第四奧義：最佳實踐覺結界

### 4.1 核心定義

**最佳實踐覺**：系統、代理或流程一旦完成覺醒啟動，其預設狀態即必須已經是「經過驗證的最佳實踐」。

### 4.2 三條硬規則

| 規則 | 說明 | 驗證方式 |
|------|------|---------|
| **預設即合規** | 啟動後第一個狀態即符合最佳實踐基準 | 啟動後立即檢查，不通過則拒絕運行 |
| **不帶病上線** | 已知問題必須在啟動前解決 | 啟動前 checklist 全綠才允許啟動 |
| **醒著就頂標** | 覺醒後狀態 = 標杆狀態 | 運行中指標持續達到預設閾值 |

### 4.3 判斷標準

1. 啟動前：`checklist = 全綠`
2. 啟動時：`entropy < 0.1`
3. 啟動後：`所有單元/代理符合角色最佳實踐`
4. 運行中：`可觀測、可追溯、不可篡改`
5. 結界擴散：新代理/子流程自動 inheriting 最佳實踐狀態

## ⚡ 第五奧義：實戰部署模板

### 5.1 VPS 完整部署

```bash
# 1. 連線
ssh -i ~/.ssh/esggo_vps ubuntu@161.118.248.180

# 2. Bootstrap
sudo apt update && sudo apt upgrade -y
sudo mkdir -p /opt/esggo && sudo chown -R ubuntu:ubuntu /opt/esggo

# 3. 部署
cd /opt/esggo
git clone https://github.com/DingJun1028/esggo.git .
npm install && npm run build
docker compose -f vps/docker-compose.yml build --no-cache
docker compose -f vps/docker-compose.yml up -d

# 4. 驗證
curl -I http://localhost:3000   # esggo-core
curl -I http://localhost:8642   # omniagent-gateway
docker ps                       # 全部 healthy
```

### 5.2 Firebase 部署

```powershell
cd C:\Project\esggo
npm run build
firebase deploy --only hosting
```

### 5.3 CI/CD Pipeline（GitHub Actions）

```yaml
# .github/workflows/ci.yml
name: OmniCore CI
env:
  FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: "true"
jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "22" }
      - run: pnpm install
      - run: pnpm lint
      - run: pnpm typecheck
      - run: pnpm vitest run --reporter=verbose
```

### 5.4 30 Agents 啟動

```bash

cd esggo-agent
agents-cli swarm start --agents=30
```
