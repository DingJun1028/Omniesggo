# 📋 最佳實踐檢查表 — PR 前自檢

> 用於每次 PR 提交前的快速自檢。覆蓋密碼管理、版本控制、CI/CD、安全等核心領域。

---

## 🚨 安全關鍵（強制通過）

### 密碼與金鑰管理
- [ ] 無真實 API key、密碼、token 寫入程式碼（`*.ts`, `*.js`, `*.py`, `*.tsx`, `*.jsx`）
- [ ] 無真實金鑰寫入 `.env` 檔案（`.env`, `.env.local`, `.env.example` 等）
- [ ] 機密檔案已 `.gitignore` 忽略
- [ ] 所有機密值遍歷 `*** MASKED ***`（對話輸出）
- [ ] 使用 `secret-vault/` 作為生產環境金鑰存放位置

### 權限與檔案
- [ ] `secret-vault/` 目錄權限 = 700
- [ ] `secret-vault/*.env` 檔案權限 = 600
- [ ] 任何機密檔案無法被其他使用者讀取

### 輸出遮罩
- [ ] 所有金鑰、token、密碼輸出全部遮罩為 `*** MASKED ***`
- [ ] 除非經過明確授權，否則不在對話中顯示實際金鑰值

---

## 📜 版本控制

- [ ] 無 `.env.local` 被提交至 Git
- [ ] 無 `secret-vault/*.env` 被提交至 Git
- [ ] 無私人金鑰、證書、憑證寫入版本庫
- [ ] PR 標題為 5T 格式（如 `feat: ...`、`fix: ...`、`docs: ...`）

---

## 🔄 CI/CD 安全

- [ ] 工作流程不包含真實金鑰（環境變數或 secrets 應使用 CI 管理）
- [ ] 工作流程不硬編碼密碼
- [ ] 工作流程使用最小權限原則
- [ ] 安全掃描腳本已執行（`scripts/daily-security-scan.ps1`）

---

## 🧹 輸出與日誌

- [ ] 程式輸出無真實機密值
- [ ] 所有日誌不記錄密碼、token、key
- [ ] 終端機歷史記錄已清除（能源事故後）
