# 墾趣旅遊永續旅程 APP — 終始矩陣全功能流動圖

> 版本：v4.0.0（單流深刻版）｜日期：2026-08-29
> 核心哲學：以終為始，始終如一，無始無終，善向永續
> 
> **終始矩陣不是點對點的清單，而是生命週期流動的圓環。**
> 每一項目都有「起→承→轉→合」四段，前者的「合」即為後者的「起」；
> 循環不息，如山脈綿延、似海浪推湧，沒有真正的起點，亦沒有真正的終點。
>
> **單流深刻原則：不是每個企業都會走完六條流。因此每一條流都必須是**
> **一次完整的、深刻的、難以忘懷的旅程。** 企業可以只走一條流，
> 但那一條流必須讓參與者終生銘記。

---

## 一、終始哲學宣言

```
           以終為始                始終如一
        ┌──────────┐          ┌──────────┐
        │ 終態圓心 │←────────→│ 初心圓心 │
        └────┬─────┘          └────┬─────┘
             │                     │
             └─────────┬───────────┘
                       ▼
               ┌──────────────┐
               │  無始無終    │
               │  善向永續    │
               └──────────────┘
```

**流動法則：**

- 刻刻（Moment-by-Moment）：每一瞬間都是「轉」，也是新的「起」
- 項目連結（Chain-by-Chain）：A→B 不是直線，而是 A 的「合」孕育 B 的「起」
- 以終為始（End-Anchors-Beginning）：永遠從終態圓心反推，但知道圓心本身也在漂移
- 始終如一（Constant-Heart）：無論流轉萬變，初心（使用者核心體驗）不動
- 無始無終（No-Start-No-End）：第一個「起」來自使用者需求，最後一個「合」又回到需求
- 善向永續（Toward-Goodness）：每一循環都朝 ESG 正向影響更進一步
- **單流深刻（Each-Flow-Complete）：每一條流都是一次完整的深刻之旅**

## 二、六流終矩陣（Six Flows of End-Beginning）

墾趣永續旅程 APP 不是六大獨立模組，而是**六流歸一**的河川體系：

```
                    ┌─────────────────────────────────────┐
                    │     善向永續（ESG 正向影響匯流）     │
                    └────────────────┬────────────────────┘
                                     │ 合（匯流）
       ┌─────────────┬───────────────┼───────────────┬─────────────┐
       │             │               │               │             │
       ▼             ▼               ▼               ▼             ▼
  ┌─────────┐  ┌─────────┐    ┌─────────┐    ┌─────────┐   ┌─────────┐
  │ 覺曉流  │  │ 凝聚流  │    │ 復元流  │    │ 共好流  │   │ 留念流  │
  │Awareness│  │Cohesion │    │Restoration│   │Mutuality│   │Memorial │
  └────┬────┘  └────┬────┘    └────┬────┘    └────┬────┘   └────┬────┘
       │             │               │               │             │
       ▼             ▼               ▼               ▼             ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │                    企業員工旅遊（基礎河床）                       │
  └──────────────────────────────────────────────────────────────────┘
```

### 六流定義

| 流名 | 核心精神 | 對應方案 | 終態圓心 | 深刻記憶點 |
|---|---|---|---|---|
| **覺曉流** 🌱 | 讓 ESG 從抽象變具體 | ESG 戶外團隊日 | 員工親身參與永續行動 | 第一次親手撿拾垃圾後的震撼 |
| **凝聚流** 🤝 | 團隊在自然中重建信任 | 高階主管共識營 | 組織對齊使命與文化 | 主管在山林間說出真心話的瞬間 |
| **復元流** 🌲 | 身心在高壓後恢復 | 員工身心平衡旅程 | 工作生活品質持續改善 | 第一次在森林中真正放下手機 |
| **共好流** 👨‍👩‍👧 | 企業關懷延伸至家庭 | 企業家庭日 | 幸福企業與雇主品牌 | 孩子第一次和父母在自然中完成任務 |
| **留念流** 📊 | 活動成果化為影響素材 | ESG Impact Note | 可量化、可分享的 ESG 故事 | 看見自己的行動被記錄成數字 |
| **基礎流** 🏔️ | 一切的核心體驗載體 | 企業員工旅遊 | 每次出行都有意義 | 每一次出遊都成為故事 |

```
├─────────────────────────────────────────────────────────────────────┤
```

## 三、每流內在四段：起承轉合 + 深刻設計

每一「流」內部皆遵循「起→承→轉→合」的生命週期。
每段皆標註「功能實作」與「深刻體驗設計」兩個層次。

---

### 3.1 覺曉流（ESG 戶外團隊日）

**單流定位：** 讓 ESG 從報告文字變成「我親手做過的真實故事」

**深刻記憶點：** 員工在 Clean-up Walk 中撿起第一片垃圾時，意識到自己正在改變世界

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        覺曉流（ESG 戶外團隊日）                          │
├──────────┬──────────┬──────────┬──────────┬───────────────────────────┤
│   起     │    承     │    轉     │    合    │  合→下一流               │
├──────────┼──────────┼──────────┼──────────┼───────────────────────────┤
│ 需求對焦 │ 場域設計 │ 戶外體驗 │ 團隊收斂 │  凝聚流 共識記錄         │
│ 訪談 HR │ 路線選擇 │ 團隊健走 │ 小組反思 │  Impact Note 數據        │
│ ESG 需求 │ 裝備提醒 │ 自然觀察 │ 行動承諾 │  家庭日 延續學習         │
│ 福委會   │ 天候備案 │ 森呼吸    │ 團隊對話 │                           │
├──────────┼──────────┼──────────┼──────────┼───────────────────────────┤
│ 深刻設計 │ 深刻設計 │ 深刻設計 │ 深刻設計 │                           │
│ ESG 前測 │ 安全故事 │ 親手行動 │ 反思提問 │                           │
│ 意識問卷 │ 學長姐   │ 即時計數 │ 承諾牆壁 │                           │
│ 基線數據 │ 經驗分享 │ 專家帶領 │ 公開宣誓 │                           │
└──────────┴──────────┴──────────┴──────────┴───────────────────────────┘
```

**單流完整閉環（不依賴其他流）：**
- 起：HR 發起 → App 建立 ESG 旅程 → 前測問卷
- 承：安全檢查 → 裝備準備 → 路線發布
- 轉：現場簽到 → Clean-up Walk → 碳足跡記錄 → 生態觀察
- 合：小組反思 → 行動承諾 → Impact Note 自動生成 → 分享傳播

**細部流動（每項目內部的微循環）：**

| 項目 | 起 | 承 | 轉 | 合 |
|---|---|---|---|---|
| Clean-up Walk | 任務卡片展示 | 參與者出發撿拾 | 記錄數量與類型 | 上傳至 Impact Note |
| 碳足跡估算 | 交通方式輸入 | 排放係數查表 | 總量計算 | 轉化為視覺化圖表 |
| 生態觀察 | 觀察記錄表單 | 拍攝/標註物種 | 專家辨識確認 | 生態報告附件 |

**深刻體驗設計：**
- **前測問卷**：活動前測量員工對 ESG 的認知程度（建立基線）
- **安全故事**：行前分享曾經參與者的轉變故事（建立期待）
- **親手行動**：每撿起一片垃圾，App 即時顯示「你已減少 X g 海洋污染」（即時回饋）
- **反思提問**：不是自由書寫，而是引導式提問「這片垃圾原本可能去哪裡？」
- **承諾牆壁**：每位員工公開展示自己的 ESG 行動承諾（社交壓力 + 動力）

### 3.2 凝聚流（高階主管共識營）

**單流定位：** 讓組織在自然場域中重新對齊使命、文化與永續轉型方向

**深刻記憶點：** 主管在山林間說出「我真正擔心的是…」的瞬間，團隊信任重建

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       凝聚流（高階主管共識營）                            │
├──────────┬──────────┬──────────┬──────────┬───────────────────────────┤
│   起     │    承     │    轉     │    合    │  合→下一流               │
├──────────┼──────────┼──────────┼──────────┼───────────────────────────┤
│ 放慢腳步 │ 連結自然 │ 領導對話 │ 共識記錄 │  Roadmap 追蹤            │
│ 遠離例行 │ 打開感官 │ 系統思考 │ 承諾行動 │  年度計畫對齊            │
│ 場域轉換 │ 信任重建 │ 跨部協作 │ 文化重塑 │  Impact Note 故事        │
├──────────┼──────────┼──────────┼──────────┼───────────────────────────┤
│ 深刻設計 │ 深刻設計 │ 深刻設計 │ 深刻設計 │                           │
│ 數位排毒 │ 信任練習 │ 結構化   │ 公開承諾 │                           │
│ 開場儀式 │ 一對一   │ 對話框架 │ 定期回顧 │                           │
│ 放下手機 │ 漫步對談 │ 第三方   │ 問責機制 │                           │
└──────────┴──────────┴──────────┴──────────┴───────────────────────────┘
```

**單流完整閉環：**
- 起：發起共識營 → 數位排毒開場 → 場域轉換儀式
- 承：Opportunity Map 畫布 → 信任練習 → 一對一漫步對談
- 轉：圓桌對話 → 系統思考引導 → 跨部門協作任務
- 合：共識記錄 → Roadmap 簽訂 → 公開承諾 → 定期回顧提醒

**細部流動：**

| 項目 | 起 | 承 | 轉 | 合 |
|---|---|---|---|---|
| Opportunity Map | 四宮格畫布 | 填寫痛點/機會 | 優先級排序 | 匯出為共識附件 |
| 3 年 Roadmap | Year 1-3 框架 | 填入 KR | 進度追蹤 | 年度回顧報告 |
| 共識記錄 | 今日共識 textarea | 集體編輯 | 確認簽核 | 發布給全員 |

**深刻體驗設計：**
- **數位排毒開場**：入場時所有手機放入密封袋，直到「合」階段才取回（儀式感）
- **信任練習**：兩人一組，一人蒙眼，另一人帶領穿越森林（身體先於心理建立信任）
- **結構化對話框架**：不是自由討論，而是「我觀察到…我擔心…我期待…」的固定句型（降低防衛）
- **公開承諾**：每位主管在全員面前宣讀自己的行動承諾（社交壓力 + 動力）
- **定期回顧**：App 每月推送 Roadmap 進度提醒，維持問責

**單流完整閉環：**

- **個人化進度報告**：每月自動生成「壓力溫度計」前後對比圖（看見改變）
- **社群支持**：匿名分享正念心得，形成支持社群（降低孤獨感）

**深刻體驗設計：**

- **互動式圖表**：可點擊、可篩選的圖表（探索感 + 控制感）
- **個人證書**：自動生成「ESG 行動參與證書」，可下載分享（成就感 + 社交貨幣）
- **分享圖**：一鍵生成個人化 ESG 影響力分享圖（降低傳播門檻）

### 3.6 基礎流（企業員工旅遊）— 承載一切

**單流定位：** 將傳統員工旅遊升級為結合自然健走、地方文化、永續學習與團隊互動

**深刻記憶點：** 每一次出遊都成為故事，而不是「又是一次出去玩」

```
┌─────────────────────────────────────────────────────────────────────────┐
│                   基礎流（企業員工旅遊）— 承載六流                        │
├──────────┬──────────┬──────────┬──────────┬───────────────────────────┤
│   起     │    承     │    轉     │    合    │  合→分流                 │
├──────────┼──────────┼──────────┼──────────┼───────────────────────────┤
│ 需求訪談 │ 行前準備 │ 現場執行 │ 成果摘要 │  → ESG（覺曉）           │
│ 訪談 HR │ 裝備建議 │ 團隊互動 │ 員工回饋 │  → 共識（凝聚）          │
│ 設定目的 │ 安全提醒 │ 地方體驗 │ 活動照片 │  → 身心（復元）          │
│ 目的地   │ 路線規劃 │ 森林慢行 │          │  → 家庭（共好）          │
│          │          │          │          │  → 報告（留念）          │
├──────────┼──────────┼──────────┼──────────┼───────────────────────────┤
│ 深刻設計 │ 深刻設計 │ 深刻設計 │ 深刻設計 │                           │
│ 需求故事 │ 行前期待 │ 現場簽到 │ 自動生成 │                           │
│ 化採集   │ 建立     │ GPS 紀錄 │ 旅程故事 │                           │
│ 個人化   │ 裝備故事 │ 即時互動 │ 數據摘要 │                           │
└──────────┴──────────┴──────────┴──────────┴───────────────────────────┘
```

**單流完整閉環：**
- 起：需求訪談 → 需求故事化採集 → 個人化旅程設計
- 承：行前準備 → 裝備建議 → 安全提醒 → 期待建立
- 轉：現場執行 → 團隊互動 → 地方體驗 → 森林慢行
- 合：成果摘要 → 員工回饋 → 活動照片 → 自動生成旅程故事

**深刻體驗設計：**
- **需求故事化採集**：不是表單，而是「你上一次深刻旅行是何時？為什麼深刻？」的敘事提問
- **行前期待建立**：出發前一週推送「目的地故事」和「學長姐經驗分享」（建立期待）
- **現場簽到儀式感**：GPS 簽到後顯示「歡迎來到 [地名]，這裡有 [N] 種特有種」（知識感）
- **自動生成旅程摘要**：活動結束後自動生成「旅程故事」圖文（降低回憶門檻）

## 四、單流深刻 vs 多流交織

### 4.1 單流獨立運作模式

當企業只選擇一條流時，APP 自動隱藏其他流入口，讓該流成為完整體驗：

```
┌─────────────────────────────────────────────────────────────────────┐
│                     單流模式（以覺曉流為例）                         │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   入口：HR 選擇「ESG 戶外團隊日」                                   │
│      ↓                                                              │
│   APP 自動隱藏：凝聚流、復元流、共好流、留念流                       │
│      ↓                                                              │
│   只顯示覺曉流完整功能：                                            │
│      ┌─────────────────────────────────────────────────────────┐   │
│      │  起：需求對焦 → 前測問卷 → 基線建立                     │   │
│      │  承：場域設計 → 安全檢查 → 裝備準備                     │   │
│      │  轉：現場簽到 → Clean-up Walk → 碳足跡 → 生態觀察       │   │
│      │  合：小組反思 → 行動承諾 → Impact Note → 分享傳播       │   │
│      └─────────────────────────────────────────────────────────┘   │
│      ↓                                                              │
│   結束時提示：「您已完成一次深刻的 ESG 之旅。                      │
│              下次可考慮延伸至『凝聚流』或『留念流』。」              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 多流交織模式

當企業選擇多條流時，前流的「合」自然孕育後流的「起」：

```
           覺曉流 ──────┐
           (ESG 日)     │
              │         ▼
              │    ┌──────────┐
              ├──→ │          │
              │    │  留念流  │ ←── 品牌部 / 公關部
              │    │ Impact   │
              │    │ Note     │
              │    │          │
              ├──→ │          │
              │    └──────────┘
              │         ▲
              │         │
           凝聚流 ──────┘
         (共識營)
              │
              │    合→企業文化重塑
              │
              ▼
         ┌──────────┐     ┌──────────┐
         │  復元流  │ ←→ │  共好流  │
         │ Wellbeing│     │ Family   │
         └──────────┘     └──────────┘
              │                │
              └──→ 基礎流 ←───┘
                   (員工旅遊)
                        │
                        ▼
              善向永續（ESG 匯流）
```

**跨流節點（Portal）：**
- 「活動照片」：基礎流 → 留念流 → 共好流 傳播
- 「共識記錄」：凝聚流 → 留念流 → 年度 Roadmap
- 「碳足跡」：覺曉流 → 留念流 → 企業 ESG 報告
- 「員工回饋」：基礎流 → 復元流 → 年度調整

## 五、圓環終態（善向永續的每一輪迴）

每一趟 APP 使用週期的「合」，同時是下一週期的「起」：

```
                         以終為始
                            │
                            ▼
              ┌─────────────────────────┐

              │   ESG 影響力持續擴大     │
              │   員工幸福感持續提升     │
              │   企業品牌持續正向       │
              └────────────┬────────────┘
                           │
         ┌─────────────────┼─────────────────┐
         │                 │                 │
         ▼                 ▼                 ▼
    ┌────────┐        ┌────────┐        ┌────────┐
    │ 覺曉流 │───────→│ 凝聚流 │───────→│ 復元流 │
    │ ESG日  │        │ 共識營 │        │ 身心平衡│
    └────────┘        └────────┘        └────────┘
         │                                   │
         │                 ┌─────────────────┘
         │                 │
         ▼                 ▼
    ┌────────┐        ┌────────┐
    │ 留念流 │───────→│ 共好流 │
    │ Impact │        │ 家庭日 │

    └────────┘        └────────┘
         │                 │
         └────────┬────────┘
```

**循環升級規則（每次輪迴的進化）：**
- 第一次循環：覺曉流（員工初步接觸 ESG）

- 第三次循環：復元流（團隊能量恢復）
- 第四次循環：共好流（關懷延伸至家庭）
- 第五次循環：留念流（成果化為品牌素材）
- 第六次循環：基礎流（升級為更豐富的員工旅遊）
- → 回到覺曉流（但已站在更高的 ESG 基準點）

## 八、實作優先順序（流動優先 + 單流深刻）

流動順序：先打通一整個「起→承→轉→合」循環，而非先完善單一模組的所有功能。
單流深刻：確保每一條流都能獨立成為深刻體驗。

| 優先 | 循環 | 項目 | 說明 |
|---|---|---|---|
| **P0** | 基礎流 → 覺曉流 | ESG 任務記錄 → Impact 數據 | 打通「覺曉→留念」路徑 |
| **P0** | 基礎流 → 凝聚流 | 共識儲存 → Roadmap 追蹤 | 打通「凝聚→留念」路徑 |
| **P1** | 復元流 | 正念計時器 → follow-up | 打通「復元」完整循環 |
| **P1** | 共好流 | 觀察記錄 → 相簿分享 | 打通「共好→留念」路徑 |
| **P2** | 留念流 | 圖表 + GRI + PPT | 完善「留念」終點輸出 |
| **P2** | 跨流 Portal | 照片分發、數據串接 | 六流匯流至善向永續 |

## 九、深刻體驗設計清單（Memory Anchor Checklist）

每條流在「合」階段必須包含以下深刻元素：

| 深刻元素 | 覺曉流 | 凝聚流 | 復元流 | 共好流 | 留念流 | 基礎流 |

| **個人化** | 即時計數 | 一對一漫步 | 引導音頻 | 分齡任務 | 個人儀表板 | 需求故事化 |
| **社交壓力** | 承諾牆壁 | 公開承諾 | 社群支持 | 親子協作 | 分享圖 | 旅程故事 |
