1. 簡介（Introduction）

OmniFactory 是 AI Station 的本地產線核心，負責將指令碼與品牌設定轉化為可交付的資產。

本地版本：所有內容皆可在無網路環境下閱讀與驗證。

2. 快速開始（Quick Start）

oa-cli init omnifactory
oa-cli request "建立一個即時股票分析平台，支援 10000 用戶並保持零成本"
oa-cli generate --project stock-analysis-platform
oa-cli deploy stock-analysis-platform
  • 0.011 秒內完成平臺生成
  • 成本：$0.00/hr
  • 延遲：7ms
  • 測試覆蓋率：100%

3. 核心功能（Core Functions）

  • 品牌一致性視覺生成
  • DNA 腳本分段解析
  • 可追蹤的產物與版本標記
  • 本地優先，可優雅降級

4. 進階操作（Advanced Usage）

支援批次處理、分頁檢視、增量輸出與快取策略。

5. 故障排除（Troubleshooting）

  • 若本機無法產生視覺，確認 Pillow 已安裝
  • 若解析失敗，檢查腳本是否包含 DNA 標記
  • 若需還原，使用前次凍結的 Hash Lock 版本

6. API 參考（Documentation）

GET /health
POST /v1/generate
GET /v1/brand

7. 安全設定（Security）

  • 本機預設不暴露金鑰
  • 公開前先通過 VaultGuard
  • 必要時才啟用外部金鑰
